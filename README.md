# VaultDrive

VaultDrive 是一套具備登入保護與帳號管理的網頁檔案中心，可用來上傳、下載、整理、重新命名與刪除團隊檔案。

## 預設管理員

- 帳號：`admin`
- 密碼：`Aa123456`

第一次登入後，系統會持續提醒管理員更換預設密碼。

## 主要功能

- 帳號密碼登入、登入失敗鎖定與 7 天安全工作階段
- 管理員可新增、停用、刪除帳號，並調整管理員／一般成員權限
- 使用 PBKDF2-SHA256 與獨立 salt 儲存密碼，不保存明文密碼
- 多檔上傳、拖放上傳與 25 MB 單檔限制
- 新增資料夾、重新命名、下載與遞迴刪除
- 檔案使用物件儲存，帳號與工作階段使用資料庫保存
- 響應式繁體中文介面

## 本機開發

需求：Node.js 22.13 以上與 pnpm 11。

```bash
pnpm install
pnpm dev
```

正式建置與測試：

```bash
pnpm build
pnpm test
```

`tests/api-smoke.mjs` 會針對正在執行的本機網站測試登入、帳號管理、密碼變更，以及檔案上傳、重新命名、下載和刪除流程。

## 資料層

- `DB`：帳號、工作階段與操作紀錄
- `FILES`：上傳的檔案與資料夾標記
- `drizzle/`：可部署的資料庫 migration
